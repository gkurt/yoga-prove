Research prototype

Formal verification for UI layout

Source on GitHub

Yoga, the flexbox engine behind React Native, is small enough to turn into plain arithmetic that a computer can reason about exactly. Each check below asks one question about a few example layouts. Instead of trying some screen sizes and text lengths, the checker covers every size in a range at once. When a layout can break, it finds an exact case, and the real Yoga engine lays that case out the same way.

Drag the sliders to change the screen size and how long each text is. The preview is laid out in your browser by the same arithmetic, number for number.
